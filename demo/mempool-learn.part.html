Learn

How miners and computers talk to each other, from bits to blocks.

1What are hashes?+

A hash is a collection of bits (0s and 1s) inside a computer, but it is shown to humans as a fixed-length string of letters and numbers.

Reading a long sequence of 0s and 1s is hard for people. To make hashes easy to read, computers translate groups of bits into a text format called hexadecimal encoding.

Hexadecimal uses 16 symbols: the numbers 0–9 and the letters A–F. That makes a hash far easier to read than the 256 or 512 bits behind it, which would be a very long string of 0s and 1s.

Every group of 4 bits is called a nibble, and every nibble turns into a single letter or number in hexadecimal:

0000000011100191010A1100C1111F

00000000000000000001a7c3f09b2e6d48c15f7e2a9b0c34d6e81f25a9c7b3e0

A 256-bit block hash = 64 hex characters (64 × 4 bits). The leading zeros are what miners search for.

2How are hashes generated?+

A hash is generated by passing data of any size through a mathematical algorithm called a hash function.

Mining hardware uses wide data buses to move bits in parallel. A miner using the hash function SHA-256 (Bitcoin) processes data in blocks of 512 bits and outputs a hash of exactly 256 bits.

A miner using BLAKE2b (Bitcoin BLAKE2b) hashes a restructured 164-byte block header. Every 8 bits make a byte, so that is 1,312 bits of input, while the hash it outputs is still exactly 256 bits.

The microscopic transistors on a mining chip perform bitwise operations (like AND, XOR and bit-shifting) directly on these streams of bits, billions of times per second.

When your mining software talks to the hashing hardware (ASIC chips or GPU cores), the bits are grouped into bytes: a 256-bit hash travels over the PCIe bus or another interface as a 32-byte array.

When you mine in a pool and your miner finds a valid share, sending raw bits over the internet is inefficient and error-prone. So the software turns the bits into a hexadecimal string: one hex character is exactly one nibble, so a 256-bit hash travels as a readable 64-character text string.

Most miners speak the Stratum protocol, to a pool or to their own DATUM Gateway, which packs these hex strings into standard JSON-RPC text messages sent over TCP.

3How does my ASIC send a share to a mining pool?+
  1. Your mining software receives the work in hexadecimal, built from your node's block template, and converts it into raw binary bytes.
  2. The raw bytes are fed into the ASIC hashing boards over an internal serial bus.
  3. The ASIC hashes the bytes and returns a 32-bit nonce (4 bytes) when it finds a share.
  4. The software sends that share back as hex text in a Stratum message, to the pool or through your DATUM Gateway.

4What is hashrate?+

Hashrate is the measure of the total computing power and speed a proof-of-work blockchain network uses to process transactions and mine new blocks: how many hashes per second (H/s, TH/s, EH/s) all miners together try.

5What is decentralised hashrate?+

Decentralised hashrate is the computing power a proof-of-work network uses to process transactions and mine new blocks with locally constructed block templates: every miner decides what goes into the block they work on.

6Centralised vs decentralised hashrate+

Centralised

Miners have little to no visibility or control over which transactions are included or excluded; they merely rent out raw hash power. A handful of large mining pools decide the contents of most of the network's blocks.

Decentralised

Miners have sovereign control and visibility over which transactions are included or excluded. They run their own Bitcoin full node (such as Bitcoin Knots or Bitcoin Core) and a protocol like DATUM Gateway that talks directly to their mining hardware.
