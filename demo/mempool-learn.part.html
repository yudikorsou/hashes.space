From bits to blocks: seven short videos

Return to Mempool

How to read the blocks

The blockchain page has two halves, split by the fan: on its left the miners build the next block, on its right the blocks they found are chained together.

Before the fan

Inside the miners

These four steps show how the block that is being hashed right now came to be. Each one is live: it is built from your own node's mempool and chain tip.

sorted by fee

1Fee sorting

Every transaction waiting in the mempool is ranked by the fee rate it pays: satoshis per virtual byte on Bitcoin and BLAKE2b, koinu per byte on Dogecoin and a fee per byte of weight on Monero. The bars move from the order the transactions arrived in to the order a miner takes them, best-paying first.

The figures are the median fee, the range from highest to lowest, and how many transactions are unconfirmed.

2Coinbase & merkle root

The first transaction of every block is the coinbase: it creates the block reward and pays it, together with the fees, to the miner. The mempool transactions follow, and they are hashed in pairs, again and again, until a single hash is left: the merkle root.

That one hash stands for every transaction in the block, so changing a single one of them changes the root.

block assembly

3Block assembly

The block is built up from nothing: the coinbase goes in first, then the transactions in the order of their fee rate, flying in one after the other. The totals count up to what your node's block template holds: transactions, fees and how full the block is.

Dogecoin and Monero show the block header being put together instead: version, the previous block, the merkle root, the time and the nonce.

0000

4Candidate block

The finished header is the candidate block, and it is what miners are hashing now. They try one nonce after the other, and every try is a hash: the strings of bits flying into the block.

A block is found when the hash falls under the target. The label above it says which block height the miners are working on.

Behind the fan

The blockchain

The glow around a mined block tells you who built its block template, the list of transactions inside. The colour of the block itself still shows the fees: the warmer, the more its transactions pay. Every proof-of-work chain has its own rules:

BitcoinSHA-256 · our own Bitcoin node

Decentralised (green glow) Only for blocks found by DATUM Gateway verified solominers of pools that are 100% DATUM. The miner built the block template on their own node and chose the transactions themselves.

DATUM Compatible (orange glow) The block was mined by OCEAN, a pool that lets its miners build their own block templates with their own node and DATUM Gateway. The pool gives miners the choice, so the block is marked as compatible with decentralised mining.

Centralised (red glow) Every other pool. The pool builds the block template, so the pool decides which transactions go in and which stay out, and its miners only rent out hash power.

Bitcoin BLAKE2bBLAKE2b · our own Bitcoin Knots node

Decentralised (green glow) Only for blocks found by DATUM Gateway verified solominers of pools that are 100% DATUM. The miner built the block template on their own node and chose the transactions themselves.

DATUM Compatible (orange glow) The block was mined by CONVOY, a pool that lets its miners build their own block templates with their own node and DATUM Gateway. The pool gives miners the choice, so the block is marked as compatible with decentralised mining.

Centralised (red glow) Every other pool. The pool builds the block template, so the pool decides which transactions go in and which stay out, and its miners only rent out hash power.

MoneroRandomX · our own Monero node

A Monero block never names its pool, so the glow comes from how the block reward was paid.

Decentralised (green glow) The block was mined on P2Pool. P2Pool is a decentralised pool: every miner runs their own Monero node and builds their own block, and the reward is paid straight to all the miners inside the block itself.

Centralised (red glow) Every other Monero block, mined on a regular mining pool. The reward is paid to a single address, the pool, which builds the block template and pays its miners out afterwards.

DogecoinScrypt · our own Dogecoin node

Centralised (red glow) Every mined Dogecoin block gets the red glow, whichever pool tag it carries, because Dogecoin pools build the block templates for their miners. No Dogecoin block gets a green or orange glow.
