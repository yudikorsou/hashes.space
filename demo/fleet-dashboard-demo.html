Find CPU

Every CPU mining rig (XMRig) that is connected to your local network, with the cores and threads it mines on. Click Manage, the dashboard can showcase the stats of one local mining rig's IP at a time.

CPU rigs can join a fleet too: set them up here, then add their IP addresses under Generate fleet on Find ASIC.

Find ASIC

Every ASIC that is connected to your local network. Click Manage, the dashboard can showcase the stats of one local mining rig's IP at a time.

Generate fleet

First set up every miner: click Manage, log in, and configure it until it shows Connected. Then paste their IP addresses (also miners in another subnet) and click Generate. You get a fleet dashboard with all of them: each miner's shares fly into the block being mined.

Open fleet dashboard

      PoW

        How to read it. The page connects to one miner at a time, picked on Find ASIC. Every share it sends to your node flies from its fan into the block being mined as a string of 0s and 1s, leading zeros first. Switch the PoW network above: a miner only hashes usefully on a network of its own hash function. This demo runs on simulated miners; the full app reads real miners of any proof-of-work hash function, and blocks from mempool.space, litecoinspace.org, mempool.guide or your own node.

        Miner settings

        Everything a miner needs to run, in one place for any brand. Each section says whether it is sent to the miner or only saved here.

        Connect to a miner first: pick one on Find ASIC or Find CPU, which list every miner powered on in your local network. Settings always apply to the one miner this page is connected to.

          Connect your own node and Electrum server

          Stream a blockchain from your own node. Pick the hash function its chain is mined with, then enter the node, an Electrum server (Electrs, Fulcrum), or both: the node gives full block details and the block your miners work on, Electrum adds the mempool.

          Node (Bitcoin Core or Bitcoin Knots)
          Electrum server

          The server connects to the addresses you enter, so your node must be reachable from it (for example through Tailscale, WireGuard or Tor). This demo can't reach your network: it checks what you type and then simulates the connection.
